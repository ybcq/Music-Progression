Real Time Recording


Using a MIDI controller, you can record MIDI data directly into Overture. The following sections discuss the process.


Basic Setup

Before you record your first track, you need to make sure that your hardware is connected and that all the software is configured properly. To do so:


  1. Make sure you have a MIDI controller and sound source connected to a MIDI interface, and that the interface is connected to your computer properly.
  2. Choose Audio/MIDI>MIDI Settings.
    Overture opens the MIDI Settings dialog box.
  3. Select your MIDI controller as an input port in the Input Devices section.
    To check if the device is working correctly, play a note on your MIDI keyboard. The box to the right of the device should turn red.
  4. Click Done.


Setting Metronome and Record Options

Next, you must make decisions concerning metronome use, voice assignments, and other recording options. To do so:


  1. From the Options>Metronome sub menu, select if and when you want the metronome to click.
    If you select Click in Record, Overture's metronome clicks for a 1-bar count off and throughout the entire recording. If you select Click in Count Off Overture's metronome clicks only during the count off measure. If you don't select either option, Overture does not play a one-bar count off before recording and the metronome does not click at all while Overture records.
  2. If you decide you want Overture to transcribe the music automatically, select a transcription quantize value with the Tool Bar's Transcription Quantize Amount button.
    For details, see Transcription Quantize Button.
  3. Decide whether or not to check the Options>Keyboard Thru option.
    This feature allows you to play a master MIDI controller and hear the output from any sound module in your studio. Generally, you should select this option if your MIDI controller and sound module are separate instruments (or you use a multi-timbral keyboard synth with its local control turned off). You should uncheck this option if you're using a single keyboard synthesizer and its Local Control is turned on. For more information, see Keyboard Thru.
  4. Using the pop-up menu at the bottom of the Score View, select a Voice to record.
  5. Choose Options>Record Options.
    Overture opens the Record Options dialog box.
  6. Select the desired record options, then click the OK button.


We discuss the Record Options dialog box in Record Options.


Recording

You're ready to start recording tracks. To do so:


  1. In the Score View, click the measure and staff at which you want recording to begin.
  2. In the Transport controls, click the Record button, or press tab.
    If you checked either the Click in Record or Click in Count Off options in the Options>Metronome sub menu, Overture counts off for one measure, then begins to record. If you didn't check any count off options, Overture begins to record immediately.
  3. Play your MIDI controller.
  4. When you're finished recording, click the Stop button in the Transport controls, or press Enter.


Overture records the MIDI data and transcribes it in the Score View. Overture automatically transcribes the music using the transcription quantize amount set with the Tool Bar's Transcription Quantize Amount button.
