System Break After Measure

Overture Menus ›› Measures Menu ›› Breaks ››

Measures>Breaks>System Break After Measure


Choose this command to force Overture to start a new system after the current measure. After this command you will see a small system break icon at the end of the measure.

Any time Overture re-flows the score, a new system will be started after this measure. If you wish to stop this behavior, delete the icon by clicking on it with the Eraser Tool.
