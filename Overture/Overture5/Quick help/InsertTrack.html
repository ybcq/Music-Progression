Insert Track

Overture Menus ›› Tracks Menu ››

Tracks>Insert Track


Choose this command to insert a new track into the score. When you choose the Insert command, the Insert Track dialog box opens.

Using the Insert Instrument Dialog Box

To insert a new track into your score:


  1. Click on the track where you want to insert the new track.
  2. Choose Score>Insert Track to open the Insert Track dialog box.
  3. Set the Options section to determine how the information derived form it's Instrument Definitions will be used for the new track.
  4. Click either the Insert before current track if you want to track below the current track. Otherwise it will be placed above the current track.
  5. Set the output device to be used for the new track.
    When you choose a device, a list of Overture's known instruments for this device will be displayed. If none are found, a list of General MIDI instruments will be shown.
  6. Choose the instrument from the panels below.


Click the Done button.
