Measures>Justify


When you choose this command, Overture calculates the pulses in the measure based on the note values contained in the measure(s) and on the spacings assigned to them internally.


Justifying a measure causes the notes within it to change their relative spacings. This greatly improves legibility, though some collision of note heads may still occur since this command does not change the width of a measure, only the spacing of notes within it. To re flow measures with the new widths, use the Score->Recalc Layout command.


To justify notes in a measure:


  1. Find the measure(s) you wish to justify.
  2. Activate the measure you wish to justify by clicking a blank space within it.

    If you wish to justify many measures simultaneously, simply select all the measures you wish to justify and choose this command.

  3. 3. Choose Measure>Justify.


Overture calculates pulses based on the note values and the spacing assigned internally.


To protect a measure from the Measures>Justify command, see Locked Measures.


Overture can automatically space notes using either Measures>Justify, and Score>Recalc Layout to re-flow the measures. These commands affect note spacing differently. To learn the differences between them, see Automatic Positioning.
