Decrease Systems on Page

Overture Menus ›› Score Menu ››

Score>Decrease Systems on Page


Choose this command to move a system from the bottom of the current page to the top of the following page, thereby decreasing the number of systems on the current page. Overture does not change the default number of systems for any remaining pages, so systems continue to wrap throughout the score (that is, the bottom system on each page moves to the top of the following page).
