Tools Panel - Text


If Tools Panel is not showing click on the Score Tools button at top left of Control Bar and then click on the Text section in the header if it's not active.

You can also type "Ctrl[Cmd]-Shift-T" to go directly to the Text section.

Text Type


  • Measure. - Text that is attached to a specific measure.
  • System - Text that is attached to a specific measure and is always displayed above the first staff.
  • Rehearsal - Text is attached to a specific measure, is always displayed above first staff, and has an enclosure.
  • Page - Text is attached to a specific page.
  • Expression - Text is attached to a specific measure and can control playback.
  • Part Extraction - Text for controlling how multiple instruments sharing a track are created, like solo, a1, a2, etc.






Text Font

  • Font - Sets the current font for new text to be entered.
  • Size and Style - Sets current font size and style  for new text to be entered.
  • Make Default - Makes this the default font for text style.
  • Replace in Score - Replaces all text of this type with current font settings.

To enter text:

  1. Select the Text type from the six choices.
    If the text type is Expression, a list of common expressions will appear below, then click on the expression text to enter.
  2. Click in the score view to enter the text. If the text was not an expression a text dialog as shown below appears for you to enter the text and the it's style.
  3. Double click the newly entered expression to change it's settings.


Note: You can drag and drop Expression text and Part Expression text directly onto the score.

To duplicate Expression text and Part Expression text:

Right click on text and and choose the destination tracks from the popup menu.



The Edit Text dialog


Font Section:

This is where you set the font typeface size and style.


Text

Type in this area to enter the text and how it is justified.


Enclosure
