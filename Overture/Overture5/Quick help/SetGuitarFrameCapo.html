Set Guitar Frame Capo

Overture Menus ›› Notes Menu ››

Notes>Set Guitar Frame Capo


Choose the Set Guitar Frame Capo command to change the fret position of chords and guitar frames.

To set the guitar frame capo position:


1. Select the desired section of guitar frames.

2. Choose Notes> Set Guitar Frame Capo.

3. Set the desired capo position.

4. Choose how to display the change.

5. Click the Done button.
