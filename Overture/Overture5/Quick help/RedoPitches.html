Redo Pitches

Overture Menus ›› Notes Menu ››

Choose this command to replace notes with pitches played from a MIDI keyboard. The selected note will be replaced with the pitches played on a MIDI keyboard and the note's duration will be preserved. The next note will then be selected and the next note will be replaced with any notes from the MIDI keyboard, and so on. When you are done, choose this command to disable Redo Pitches.


Using the Notes/Redo Pitches Command

To redo pitches:


  1. Using the Arrow cursor, click the first note in the passage to select it (highlighting it).
  2. Choose Notes/Redo Pitches.
  3. Play notes on your MIDI keyboard. The selected note is replaced by the pitches played on the MIDI keyboard and the next note is selected.
  4. Choose Notes/Redo Pitches to disable Redo Pitches.
