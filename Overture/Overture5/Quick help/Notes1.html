Engraver Panel - Notes Section


If the Layout panel is not showing click on the Layout button at top right of Control Bar or type "Shift-L" to open the panel.

Then choose the Engraver panel and then the Notes tab.




Apply Note Spacing - allows you to set the distance between note elements.


Slider - a simple way to tighten or loosen the distance between notes.


Normal - Uses the setting below in Note Spacing.

Fibonacci - Sets the spacing between each note by a Fibonacci scaling factor of 1.618.

Proportional - Set the distance based on note value. Eight note is half the distance of quarter note.




Note Spacing - allows you to set the distance between each note type.











Grace Notes - allows you to set the distance around grace notes.
