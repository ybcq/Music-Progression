Selecting tracks

All about Tracks ››

There are several ways to select tracks.


When working in the Score View clicking on any track makes it the current track.


When in the Data View clicking on any track in the Track List makes it the current track.


Choosing a track from the pop-up menu in Graphic View makes it the current track.


If you click on a track while the Track Inspector Panel is open, you will see the track's settings.
