File>Import


Choose this command to import either a Music XML or standard MIDI file, and convert it into standard music notation.


  1. Choose File>Import
    The Open dialog box appears.
  2. Navigate to where you store your files.
  3. Select the file you wish to import and click Open. If the file is a MIDI file, the Import File dialog box appears.
  4. Enable those tracks you wish to import and select the desired voicing, split, quantization and transcription options for each track.
  5. Click the OK button.
