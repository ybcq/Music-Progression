Hold Note Values

Overture Menus ›› Options Menu ››

Options>Hold Note Values


Select this option to hold note values constant in situations where they would otherwise be altered. For example if you selected a quarter note that sounds more like an eighth note and typed '8' to change it's notated value, the notes' start time and duration will not be affected if Hold Note Values is selected. Otherwise the note's duration would be changed to the duration of an eighth note. This command is usually used when editing notes that were recorded in real time or notes from an imported MIDI file and you want to maintain their original playback.


Also if you delete a note with Hold Note Values off, the notes following this note will be moved to the left. If you delete a note with Hold Note Values on, the deleted note will be replaced by a rest. If you then delete the rest the following notes will be moved to the left.
