Erase Button


Click the Eraser button to select the Eraser tool. The cursor becomes an eraser when you move it over the Score View. Use the Eraser tool to delete musical symbols by clicking them.


You can type the letter e (for Eraser) to activate the Eraser tool (unless you're using one of Overture's text-entering tools).

If you delete any note other than the last in the measure, the timing for notes later in that measure changes by the amount of time of the deleted note because by default Overture does not automatically insert a rest where the note was deleted. You alter note timings when you delete a note in the Score View. If you want Overture to replace a deleted note with a rest, use the Options>Hold Note Values menu option.


For example, deleting the second quarter note in a measure with four quarter notes moves the last two quarter notes earlier by one quarter note.

Overture changes note timings after you delete a note except when


  • you record notes in real time but they have not yet been transcribed. Overture calls these raw notes.
  • you delete the last note in a measure.


In the first case, the notes appear in the Score View as bars. Deleting a note has no effect on the timing of the next note because the note timings are raw and have not been transcribed. The second case doesn't require editing because there are no notes later in the measure to encroach on the time deleted with the note.


See Hold Note Values for avoiding these situations.
