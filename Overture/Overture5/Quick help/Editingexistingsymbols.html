Editing existing symbols

Getting Started ›› Entering symbols ››

Overture has many tools for adjusting score elements. In many instances, it is not necessary to specially select them; you can just move the pointer over the element and the pointer will change shape to let you know that you can now edit the element.

Dragging symbols

To drag any symbol, select the selection cursor from the Control bar (or type esc). Position the cursor over the symbol, then click and drag.

Erasing symbols

To erase any item from the score, select the eraser cursor from the tool bar (or type e). Position the cursor over the note or symbol you wish to delete and click.
