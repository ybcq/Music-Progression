Save>Recalc Layout


When you choose this command, Overture uses existing measure widths to flow measures along systems and systems are flowed through pages.

Any page, system, or measure breaks are also used while flowing systems and measures. See Measures>Breaks for more information.


Recalculating a layout causes some measure widths to expand and others to contract. This has the effect of changing the number of measures in many of the systems and even changing the number of systems and pages in a score. This greatly improves legibility since it eliminates the collision of note heads, but it can play havoc with a carefully tweaked score. For this reason, you should recalculate a score before you fine tune it.


Overture distributes measures along systems based on internal calculated widths. If you have Auto>Space Notes enabled, as you make edits to a measures, Overture automatically spaces notes within a measure. The notes spacing in determined by allotment tables that can be set in the Engraver>Notes panel.


To protect a measure from the Save>Recalc Layout command, see Locked Measures.


Overture can automatically space notes using either Options>Auto Position, Measures>Justify, or Score>Recalc Layout. All three of these commands affect note spacing differently.
