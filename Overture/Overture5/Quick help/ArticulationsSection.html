Track Inspector Panel - Articulations Section


If the Articulations  panel is not showing click on the Inspector button at top right of Control Bar or type "Shift-I" to open the panel. Then choose Articulations























Use this section to define how articulations affect playback on the current track. Any new articulations you enter will use these for its playback data. All settings are saved with the score.


Articulation Option - Choose the articulation to edit

  • Normal - Use this to select the set of standard articulations.
  • Jazz - Use this to select the set of jazz articulations.


Apply Button - Use this button to change existing articulations in your score of this type with these settings.

This will replace any selected articulations of this type in the current track.

If nothing is selected it will change all articulations of this type in the current track.


Playback Options

Use the Playback Options portion to affect note data and playback timing.


  • You can use the attack and duration settings to create rolled chords.
  • Use the velocity settings to create dynamic changes.
  • Use the pause setting for Fermatas.
  • Use the tremolo settings for creating measures and unmeasured tremolos.


Send MIDI

Use theses options to send controller data, program changes, and key switches, to the output device, or even change to another voice within the track.


  • At note start - Choose this to send the settings at the start of the note's playback.
  • At note end - Choose this to send  the settings at the end of note's playback.
  • Offset by - Use this to offset the articulation's starting playback time.
  • Use Voice - Choose this option if you want the articulation to force a track to use the playback setting for a different voice. Ex. If voice 1 is a normal violin sound on channel 1 and voice 2 is a pizzicato sound on channel 2, an articulation entered on voice 1 could force this note in voice 1 to start play using voice 2 settings. In other words, send this voice 1 note out on channel 2 instead of channel 1.
  • Bank Change - Choose this option if you want the articulation to send MIDI bank change on this track.
  • Prg Change - Choose this option if you want the articulation to send MIDI data that changes the sound in a track.
  • Key Switch - You can send key switch data to MIDI or VST devices to switch instruments or modes.
    Choose this option if you want the articulation to send a key switch. Key switches are
    used by sample libraries to switch styles within a sample. The popup menu only shows the valid key switches for this track and voice.
    If you wish to see all possible key switches, check the appropriate setting in the Preferences dialog.
    • Velocity - Set the velocity to be used by this key switch.
  • Controller - You can send controller data to changes MIDI settings or access effects in MIDI or VST devices or VST instruments.
    • Value - Set the value to be sent with this controller.


The possibilities are limitless with theses commands
