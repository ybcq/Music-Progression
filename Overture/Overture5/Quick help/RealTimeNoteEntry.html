Real Time Note Entry

Getting Started ›› Entering notes ››

Using a MIDI controller, you can record MIDI data directly into Overture. The following sections discuss the process.

Basic Setup

Before you record your first track, you need to make sure that your hardware is connected and that all the software is configured properly. To do so:

  1. Make sure you have a MIDI controller and sound source connected to a MIDI interface, and that the interface is connected to your computer properly.
  2. Choose Audio/MIDI>MIDI Settings.
    Overture opens the MIDI Settings dialog.
  3. Select your MIDI controller as an input port in the MIDI Settings dialog by clicking on the Enable/Disable text. Clicking here toggles the enable/disable state.
  4. Click Done.

Setting Metronome and Record Options

Next, you must make decisions concerning metronome use, voice assignments, and other recording options. To do so:

  1. From the Options>Metronome sub menu, select if and when you want the metronome to click.
    If you select Click in Record, Overture's metronome clicks for a 1-bar count off and throughout the entire recording. If you select Click in Count Off, Overture's metronome clicks during the count off measure. If you don't select either option, Overture does not play a one-bar count off before recording and the metronome does not click at all while Overture records.
  2. Decide whether you want the recorded music to be auto beamed, auto positioned, or auto transcribed by checking the appropriate options in the Options menu.
    We discuss each of these options in detail in the Options Menu.
  3. If you decide you want Overture to automatically transcribe the music, select a transcription quantize value with the Control Bar's Transcription Quantize button.
    For details, see Transcription Quantize Button.
  4. Decide whether or not to check the Options>MIDI>Keyboard Thru option.
    This feature allows you to play a master MIDI controller and hear the output from any sound module in your studio. Generally, you should select this option if your MIDI controller and sound module are separate instruments (or you use a multi-timbral keyboard synth with its local control turned off). You should uncheck this option if you're using a single keyboard synthesizer and its Local Control is turned on. For more information, see Keyboard Thru.
  5. Using the View pop-up menu on the Control bar, select a Voice to record. You can also use Ctrl[cmd] 1-8 keyboard shortcut.
  6. Choose Options>Preferences and then the Record Tab to set recording options.
  7. Select the desired record options, then click the Done button.
    We discuss the Record Options dialog in Record Options.

Recording

You’re ready to start recording tracks. To do so:

  1. In the Score View, click the measure and staff at which you want recording to begin.
  2. In the Control bar, click the Record button, or press the enter key.
    If you checked either the Click in Record or Click in Count off Only options in the Options>Metronome sub menu, Overture counts off for one measure, then begins to record. If you didn't check any count off options, Overture begins to record immediately.
  3. Play your MIDI controller.
  4. When you're finished recording, click the Stop button on the Control bar, or press the space bar.


Overture records the MIDI data and transcribes it in the Score View. If you selected Options>AutoTranscribe, Overture automatically transcribes the music using the transcription quantize amount set with the Control Bar's Transcription Quantize button.
