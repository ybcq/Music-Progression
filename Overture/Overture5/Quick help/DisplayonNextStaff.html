Display on Next Staff

Overture Menus ›› Notes Menu ››

Choose this command to display the selected notes on the staff below their current one.


This command can only be used on instrument tracks that have multiple staves like Piano and Organ.


Use this command for cross-staff beaming. See Cross-Staff Beaming for more information.


The Display on Next Staff command does not actually move note data from one track to another, it only changes which staff displays the notes. If you wish to move note data to the next staff, use the Move to Next Staff command (discussed in Move to Next Staff).
