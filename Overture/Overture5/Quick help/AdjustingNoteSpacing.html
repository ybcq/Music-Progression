Adjusting Note Spacing

There are numerous ways to adjust the spacing of notes in the Score View:

  • Drag notes (or groups of notes) to change their position relative to other notes.
  • Nudge notes (or groups of notes) with the arrow keys to make small changes in their position relative to other notes.
  • Change the bar width to expand or contract the spacing of notes in a measure.
  • Automatically position notes. There are two ways to do this:
  1. Automatically align existing notes (using the Measures>Justify command).
  2. Automatically adjust measure width and spacing (using the Score>Recalc Layout command).


The following sections detail each of the preceding techniques.


Dragging Notes

You can drag a note to change its position relative to other notes.

Also, you can drag any note in a chord to change the horizontal spacing of the entire chord.

You can select and drag notes and chords, as well as dynamics, hairpins, text repeats, and Graphics palette objects as a group.


Nudging Notes

You can nudge notes either left or right in small increments. To do so:


  1. Select the note (or notes) you want to nudge.
  2. Type the left arrow key to nudge the notes to the left. Type the right arrow key to nudge the notes to the right.


Each horizontal nudge moves the symbol approximately a single pixel. Overture prints at a resolution of 1/72 of an inch so, at 100% scaling, you can nudge symbols at a resolution of 1/72 of an inch on the printed page.


Changing Bar Widths

You can proportionally compress or expand the spacing between all notes in a measure by changing the width of the bar. To do so:


  1. Select Options>Show>Handles.
    This is an optional step. Once you learn where to click on a staff or barline, you won't need to select this option. Handles are always available, they're just normally invisible. Selecting this option shows you where to click a staff or barline to edit it.
  2. Drag the desired bar's handle to the left or right.


The figure shows the middle bar dragged to the left. This results in tighter spacing in the first measure and wider spacing in the second.

Bar widths also change when you use the Measures>Increase on System or Measures>Decrease on System commands since these actions place a different number of bars on a single, fixed width line. For more information about wrapping measures, see Measures>Increase on System and Measures>Decrease on System.


Automatic Positioning

There are two ways to space notes automatically in a score. The following discusses the differences between these three automatic note spacing algorithms:


  • Measures>Justify: When you choose this command, Overture calculates a new spacing based on the note values and the amount of space allocated to them internally. It then spaces notes accordingly (without changing the width of the measure)
    For a detailed discussion of the Measures>Justify command, see Justify.
  • Score>Recalc Layout: When you choose this command, Overture layouts the pages using the inter calculated measure widths.


For a detailed discussion of the Score>Recalc Layout command, see Recalc Layout.
