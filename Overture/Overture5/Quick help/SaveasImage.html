Save as Image

Overture Menus ›› File Menu ››

File>Save as Image


Choose this command to either save your current page as a graphic image. When you choose the Save As command, Overture produces a standard Save As dialog box.

Type the desired name into the text field using one of the extensions .jpg, .png, or .gif to determine what type of graphic file to save. Then navigate to a storage location. Click the Save button to save the current score as an image file.
