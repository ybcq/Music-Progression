Delete Measure

Overture Menus ›› Measures Menu ››

Measures>Delete Measure


Choose this command to delete one or more contiguous measures beginning with the active measure. The active measure is the measure that contains the insertion point. When you choose the Delete command, Overture opens the Delete Measure dialog box.

Using the Delete Measure Dialog Box

To delete one or more contiguous measures from your score:


  1. Click in the first measure you wish to delete.
  2. Choose Measures>Delete.
    Overture opens the Insert Measure dialog box.
  3. Use the numerical to enter the number of measures you wish to delete.
    In this example, we choose to delete one measure.
  4. Click the OK button.
    Overture deletes the requested number of measures beginning with the active measure.
