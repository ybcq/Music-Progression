Export as MusicXML File

Overture Menus ›› File Menu ›› Export ››

File>Export>Export as MusicXML File


When you choose this command, Overture opens a standard Save As dialog box.

Use the dialog box to tell Overture what to name the resulting MusicXML file and where you want it saved.
