Browser Panel


If the Browser panel is not showing click on the Browser button at top right of Control Bar or type "Shift-B" to open the panel.


The Browser Panel has four sections for loading and importing scores and files.

Tabs - allows you to choose what type of file to load.

  • Score - Displays all Overture scores in the selected folder.
  • Templates -  Displays all Overture templates.
  • MusicXML - Displays MusicXML files in the selected folder.
  • MIDI - Displays MIDI files in the selected folder.
