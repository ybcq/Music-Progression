File>Save


Use this command to save the active score in the same folder you last saved it in. This command always saves scores in the Overture file format. If you want to save a score using a different format, use the Export command.

If you choose the Save command for a score that has never before been saved, you will be prompted to name the file using the standard Save As dialog box. We discuss the Save As dialog box below.
