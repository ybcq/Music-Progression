Edit Hairpin Dialog

Double-click a hairpin in the Score View to open the Edit Hairpin Dialog Box box.


Set the type of playback to Velocity, Volume, Modulation, or Expression. Set the Value field to the start, middle, and ending values to be used during playback. Select the Play option to use the selected Value setting during playback. Select the All Voices option to have this hairpin affect all voices in the track. Select the Change All Of This Type option to change other hairpins of the selected type to the selected settings. Overture plays hairpins by sending MIDI controller data such as volume or by changing note velocities over the duration of the hairpin
