Space Notes

Overture Menus ›› Options Menu ›› Auto ››

Options>Auto>Space Notes


When you select this option, Overture automatically spaces any new notes that you enter. When you check the option, Overture spaces notes according to the measure's existing Beat Chart without changing the width of the measure. When you deselect the option, Overture displays notes exactly where you enter them.


Overture can automatically space notes using either Options>Auto>Justify, Measures>Justify, or Score>Recalc Layout. All three of these commands affect note spacing differently. To learn the differences between them, see Automatic Positioning.
