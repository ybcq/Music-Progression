Overture Menus

Overture has numerous menus under which it groups related commands and options. The following sections present a brief overview of Overture's different menus.


File Menu

Use the File menu commands to save, create, open, export, and print the various scores you create with Overture.


Edit Menu

Use the Edit menu commands to cut/copy/paste symbols, lyrics, MIDI data, or other elements of an Overture score. Edit commands use a Clipboard concept common to most Windows programs. Overture uses both an internal Clipboard and the Windows Clipboard depending on the type of data.


Score Menu

Use the Score menu commands to perform score-related tasks like staff location and appearance; system groupings; and page setup.


Tracks Menu

Use the Tracks menu commands to perform track-related tasks like insert and delete tracks.


Measures Menu

Use the Measures menu commands to perform measure-related tasks like inserting and deleting measures; wrapping measures; setting key, meter and tempo; and justifying symbols in a measure.


Notes Menu

Use the Notes menu commands to perform many common Overture tasks like modifying notes; transposing; beaming; grouping; and converting between traditional notation and raw MIDI data.


Options Menu

Use the Options menu to set numerous Overture operating, editing, and display options like auto beaming and positioning, metronome values, and recording choices.


Audio/MIDI Menu

Use the Audio/MIDI menu to set set the audio playback, MIDI settings, record audio output to disk, and manage VST/AU plugins.


Windows Menu

Use the Windows menu commands to open (or make active) any Overture window or view.


Help Menu

se the Help menu to see help available for Overture.
