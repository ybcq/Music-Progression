Save As

Overture Menus ›› File Menu ››

File>Save As


Choose this command to either save an existing score under a new name, or save a new score. When you choose the Save As command, Overture produces a standard Save As dialog box.

Type the desired name into the text field and use the pop-up menu and scroll list to select a storage location. Click the Save button to save the file.
