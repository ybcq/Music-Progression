Based on Meter

Overture Menus ›› Notes Menu ›› Beam ››

Notes>Beam>Based on Meter


Choose this command or press Ctrl[Cmd]-b to beam the selected notes and group them based on the meter of the measure(s). Define beam groupings in the Set Meter dialog box (accessed by choosing Measures>Set Meter). See Set Time Signature for more information about the Set Meter dialog box.
