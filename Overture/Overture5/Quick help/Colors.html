Preferences>Colors



There are numerous elements in the Colors tab, as follows.


Theme: Choose the color theme to use and set the opacity level for dialogs.


Voice Colors. Use this option to set the colors for each voice. Use the Options>Show>Symbols in Colors menu command to enable or disable showing symbols in color.
