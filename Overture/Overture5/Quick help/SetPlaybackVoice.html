Set Playback Voice

Overture Menus ›› Notes Menu ››

Choose Set Playback Voice>Default (1-8) commands to change the playback information for the specified voice. The playback settings are found in the track List window.

This is useful for instruments that switch to different playing styles within a passage.


For example let's say we have a violin passage where the first four notes are played legato and the next four notes are played staccato.


  1. In the Track's Window set this Track's voice one set to a legato violin instrument and voice two to a staccato violin by specifying different channels (and program changes if needed).
  2. Enter all eight notes in voice one.
  3. Select the second four notes and choose Set Playback Voice>Voice 2.


Overture will play the first four notes using the legato violin instrument and the play the second four notes using the staccato violin instrument.
