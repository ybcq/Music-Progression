Use the Controller tool to draw MIDI Controller data directly on your score.


To enter controller data:


  1. Choose the controller type from the pop-up menu.
  2. Click in the staff and measure and and while holding down the mouse drag horizontally and vertically.
  3. To replace existing controller data simply draw over the data.
  4. To erase existing controller data, choose the eraser tool and draw over the data to erase.


NOTE: Use the Quantize button to set horizontal resolution. Be sure to reset it afterwards.
