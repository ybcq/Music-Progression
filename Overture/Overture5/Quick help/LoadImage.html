Load Image

Overture Menus ›› File Menu ››

File>Load Image


Use this command to load a graphic image onto your score.


When you choose the Load Image command, a standard Open dialog box appears. Use the Open dialog box to navigate through your various volumes and folders to locate the desired graphic file. Click the file to select it, then click the Open button. The Open dialog box disappears and the selected image is place onto the score at the current location.
