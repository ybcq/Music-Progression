Tie

Overture Menus ›› Notes Menu ›› Group ››

Notes>Group>Tie


Choose this command to tie together any notes of the same pitch within the selected group. To create a tie in your score:


  1. Ctrl[Cmd]-click each note you want to tie together.
  2. Choose Notes>Group>Tie.
    Overture ties the selected notes together.


If you draw a rectangle around a contiguous group of notes, then choose the Tie command, Overture ties together any notes of the same pitch within the selected group.


You can select a single note and attach a tie mark to it. This lets you create a note that's tied to a different place in the score (such as an ending, coda, etc.).


Using the Tie command is the same as selecting the Tie tool from the Groups palette and grouping notes in the Score View.


MIDI playback recognizes tie markings. For instance, if you tie two quarter notes together, then your MIDI module plays the tie as though it were a half note.
