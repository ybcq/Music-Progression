How do I add text to a measure or a page?


Overture allows you to add any text you want to a page or measure using the Text Panel.


Use the Page Text  to add text to a page that stays on that page, no matter how you arrange the staves and measures.
Use the Measure Text  to add text to a measure, allowing the text to flow with that measure wherever it moves on the page.


To add a rehearsal mark, use the Rehearsal Mark on the Text palette instead.


To add lyrics, use the Lyrics Panel instead.
