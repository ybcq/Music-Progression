New

Overture Menus ›› File Menu ››

File>New


Choose this command to open a new, untitled score.


When you choose the New command, a New Score dialog appears. Use the dialog to to enter your new score attributes.


You can have up to four open scores as memory allows. To switch between open scores, select the appropriate score from the Windows menu.
