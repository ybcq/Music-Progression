Create from Template

Getting Started ››

In the Templates folder are a number of templates using different formats. Open them and look at the staff and page settings to get a feel for their design. You can create your own templates, too. One of the best ways to learn is by example, so don't be shy!



  1. From the Template Folder section choose the main device.
  2. From the Template section choose the actual template for this device.
  3. Set the initial title, key signature, etc. on the right side of dialog.
  4. Click the Done button to create the new score.
