Edit Key Bindings

Overture Menus ›› Options Menu ››

Options>Edit Key Commands


Choose this command to edit Overture's key bindings. When you choose the Options>Edit Key Commands, Overture opens the Edit Key Commands dialog.

The Key Bindings dialog lets you remap the computer keyboard short cut keystrokes that execute Overture's commands.
