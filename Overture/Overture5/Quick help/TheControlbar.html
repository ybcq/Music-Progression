The Control bar

Getting Started ›› Main Score Window ››

The Control bar contains buttons to open views, transport buttons for playback, a time display to show current location, and several global settings.


Left side of Control bar

  • Library button - Opens and closes the Library panel.
  • Tools Button - Opens and closes the Tools panel.
  • Score View Button - Opens or closes the main score view.
  • Data View Button - Opens or closes the Data Views
  • Mixer View Button - Opens or closes the Mixer view.
  • Selection Button - Changes to selection mode.
  • Pencil Button - Changes to insert mode.
  • Eraser Button - Changes to erase mode.

Middle left of Control bar

  • Rewind Button - Moves the current location to the beginning of score.
  • Play from Beginning Button - Starts playback at beginning of score.
  • Play Button - Starts playback at current position.
  • Record Button - Start recording data on the current track at current position.

Time Display

  • Displays the current location in the score.
  • Right click to set display options or go to a bar or page.

Middle right of control bar

  • Metronome Button - Enables metronome sound when playing or recording.
  • Loop Button - Enable and set loop playback or ctrl[cmd] click to enable and set Replay position.
  • Quantize Button - Set value to be used when transcribing notes during record on using Transcribe menu command.
  • Show Transpose Score Button - Displays all tracks in Concert key or the track's transposed key.

Right side of Control bar

  • Score/Part Toggle Button - Toggles between the main score and active part.
  • Active Part Button - Chooses the active part to be displayed and edited.
  • Linear View Button - Toggles between normal score view and linear view.
  • View Menu button - Used to choose how score is displayed in window.
  • Score Layout Button - Opens and closes the Score layout panel.
  • Browser Button - Opens and closes the Browser panel.
  • Inspector Button - Opens and closes the track inspector panel
