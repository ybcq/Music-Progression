How do I open a Overture song in another music program?


Since most music software programs can open MIDI files, create a MIDI file of your song. Use Overture's Export MIDI File feature (File>Export>As MIDI File).


or


If your program can import a MusicXml file use Overture's Export MusicXml File feature (File>Export>As MusicXml File).


For more information on Overture's use of MIDI files, see File>Export.
