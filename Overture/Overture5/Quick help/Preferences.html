Options>Preferences


Choose this command to select, set or view numerous Overture preferences. When you choose the Options>Preferences, Overture opens the Preferences dialog box.

The top of the Preferences dialog box displays [tabs]. This menu contains [five] different types of preferences:


  • General
  • Playback
  • Recording
  • Colors


When you select one of the [tabs], the Preferences dialog box displays the selected tab or type. The following sections describe each preference and option in detail.
