Exportation MusicXML

Le menu  Fichier > Exporter > MusicXML permet d'exporter des fichiers Guitar Pro vers le format MusicXML.

 

Créé par Recordare®, MusicXML est une description XML d'une partition musicale.

Ce format d'échange universel est maintenant disponible dans la plupart des logiciels de musique.
