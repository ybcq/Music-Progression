Importation TablEdit

Le menu  Fichier > Importer > TablEdit permet d'importer des fichiers Tabledit® dans Guitar Pro.

 

TablEdit® est un excellent éditeur de tablatures, dans le même esprit que Guitar Pro mais avec une approche différente. Il est disponible sur http://www.tabledit.com.
