Le menu Effets

  Note étouffée

Insère un note étouffée à la position du curseur d'édition.

 

A lire : Ajouter des symboles > Note étouffée

 

  Appoggiature >

Insère un appoggiature (avant ou sur le temps) à la position du curseur d'édition.

 

A lire : Ajouter des symboles > Appoggiature

 

  Note suggérée [O]

Indique une note suggérée à la position du curseur d'édition.

 

A lire : Ajouter des symboles > Note suggérée

 

  Note accentuée

Indique une note accentuée à la position du curseur d'édition.

 

A lire : Ajouter des symboles > Note accentuée

 

  Note fortement accentuée

Indique une note fortement accentuée à la position du curseur d'édition.

 

A lire : Ajouter des symboles > Note fortement accentuée

 

  Staccato

Indique un staccato sur la note sélectionnée.

 

A lire : Ajouter des symboles > Staccato

 

  Staccatissimo

Indique un staccatissimo sur la note sélectionnée.

 

  Tenuto

Indique un tenuto sur la note sélectionnée.

 

  Legato

Indique un legato sur la note sélectionnée (uniquement sur certains types d'instrument comme le piano).

 

A lire : Ajouter des symboles

 

  Laisser sonner

Indique que la note sélectionnée est en let ring (laisser sonner).

 

A lire : Ajouter des symboles > Let Ring
A lire : Utiliser les assistants

 

  Palm Mute sur la note

Indique un palm mute sur la note sélectionnée.

 

A lire : Ajouter des symboles > Palm Mute
A lire : Utiliser les assistants

 

  Palm Mute sur le temps

Indique un palm mute sur le temps sélectionné.

 

A lire : Ajouter des symboles > Palm Mute
A lire : Utiliser les assistants

 

  Harmonique naturelle

Indique une harmonique naturelle sur la note sélectionnée.

 

A lire : Ajouter des symboles > Harmonique naturelle

 

  Harmonique artificielle

Ouvre la fenêtre permettant de choisir une harmonique artificielle ainsi que son type sur la note sélectionnée.

 

A lire : Ajouter des symboles > Harmoniques artificielles

 

 

  Bend...

Ouvre la fenêtre de configuration du bend

 

A lire : Ajouter des symboles > Bend

 

  Barre de vibrato ...

Ouvre la fenêtre de configuration du vibrato chevalet

A lire : Ajouter des symboles > Barre de vibrato
 

  Slide

Indique un slide sur la note sélectionnée.

 

A lire : Ajouter des symboles > Slides

 

  Vibrato

Indique un vibrato main gauche sur la note sélectionnée (léger ou ample).

 

A lire : Ajouter des symboles > Vibrato

 

  Vibrato au chevalet

Indique un wide vibrato (ou coup de vibrato) sur le temps sélectionné (léger ou ample).

 

A lire : Ajouter des symboles > Wide Vibrato

 

  Slide

Permet de choisir un des 6 types de slide disponibles.

 

A lire : Ajouter des symboles > Slides

 

  Hammer On / Pull Off

Indique un HO ou PO sur la note sélectionnée (en fonction de la valeur de la note suivante).

 

A lire : Ajouter des symboles > Hammer On / Pull Off

 

  Tapping main gauche

Indique un tapping main gauche sur la note sélectionnée.

 

A lire : Ajouter des symboles

 

 

  Tapping

Indique un tapping sur la note sélectionnée.

 

A lire : Ajouter des symboles > Tapping

 

  Slap

Indique un slap sur la note sélectionnée.

 

A lire : Ajouter des symboles > Slap

 

  Pop

Indique un pop sur la note sélectionnée.

 

A lire : Ajouter des symboles > Pop

 

  Trille...

Ouvre la fenêtre permettant de configurer le trille désiré sur la note sélectionnée

 

A lire : Ajouter des symboles > Trill

 

  Tremolo Picking

Indique un tremolo picking sur la note sélectionnée.

 

A lire : Ajouter des symboles > Tremolo Picking

 

  Palm Mute

Indique un palm mute sur la note sélectionnée.

 

A lire : Ajouter des symboles > Palm Mute
A lire : Utiliser les assistants

 

  Fade In

Indique un fade in sur le temps sélectionné.

 

A lire : Ajouter des symboles > Fade In

A lire : Ajouter des symboles >
