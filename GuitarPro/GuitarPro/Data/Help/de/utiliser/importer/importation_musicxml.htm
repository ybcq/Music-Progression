MusicXML Importieren

Durch Auswahlüber das Menü Datei > Importieren > MusicXML, kõnnen Sie eine XML-Datei im MusicXML Format importieren.

 

MusicXML ist eine XML Beschreibung für Musikpartituren, die von Recordare® entwickelt wurde.

 

Dieses allgemeingültige Austauschformat wird nun von den meisten Programmen für Musiksoftware benutzt.
