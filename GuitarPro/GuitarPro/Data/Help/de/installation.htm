Installation

A. Mindestanforderungen abhängig von Ihrem Betriebssystem

1. Windows ® XP/Vista/Win7 oder Ubuntu (offiziell unterstützt GNU Linux Distribution)

 

Minimale Systemanforderungen (MIDI-Wiedergabe)

  • Administrator-Rechte für die Installation; Internetverbindung zur Aktivierung*

  • Intel Pentium-4-Prozessor-Typ

  • 1 GB RAM mit 256 MB freier Speicherplatz auf der Festplatte

  • Soundkarte - DVD-ROM-Laufwerk

Minimale Anforderungen mit RSE (Realistic Sound Engine)

  • Administrator-Rechte für die Installation; Internetverbindung zur Aktivierung*

  • Intel Core 2 Duo 2.4GHz

  • 2 GB RAM, 2 GB freier Festplattenspeicher

  • Soundkarte - DVD-ROM-Laufwerk

* Mõglichkeitüber einen anderen Computer zu aktivieren, der mit dem Internet verbunden ist.

 

 

2. Mac OS X 10.4 oder später

 

Minimal Requirements (MIDI Playback)

Minimal requirements with the RSE (Realistic Sound Engine)

B. Installation mit Windows®

1. Um Guitar Pro zu installieren

  • Legen Sie die Guitar Pro DVD-ROM in Ihr Laufwerk ein.

  • Wenn das Setup-Programm nicht automatisch startet, doppelklicken Sie auf Arbeitsplatz, doppelklicken Sie auf DVD-ROM-Laufwerk, dann doppelklicken Sie auf Windows/setup.exe Datei und folgen den Anweisungen.

  • Die Installation von Guitar Pro wird eine Verknüpfung zu der Software auf dem Desktop als auch in Start - Programme- Guitar Pro 6-Menü von Windows ®.

  • Wenn Sie die Soundbanken noch nicht installiert haben, und Sie mõchten die später installieren, õffnen Sie einfach die GPBANK-Datei, die Sie auf der DVD finden, mit Guitar Pro im Menü Datei/õffnen oder durch Abwurf auf die Dateiüber das Guitar Pro Hauptfenster.

 

2. Um Guitar Pro zu starten

Um Guitar Pro zu starten, doppelklicken Sie auf Start auf der Guitar Pro Verknüpfung auf dem Desktop, oder verwenden Sie das Start- Programme- Guitar Pro 6-Menü.

 

 

3. Um Guitar zu deinstallieren

Wenn Sie Guitar Pro deinstallieren wollen, benutzen Sie bitte das Menü:

Start – Programme – Guitar Pro 6 desinstallieren.

 

 

C. Installation unter GNU Linux

1. Um Guitar Pro zu installieren

  • Legen Sie die Guitar Pro DVD-ROM im Ihr Laufwerk

  • Doppelklicken Sie auf DVD-ROM-Laufwerk, doppelklicken Sie dann auf "GuitarPro6.deb"-Datei. Das wird den Paket-Installer starten.

  • Klicken Sie auf "Installieren Sie das Paket" und geben Sie Ihren Benutzernamen ein.

  • Um Soundbanken zu installieren, õffnen Sie einfach die GPBANK-Datei, die Sie auf der DVD finden, mit Guitar Pro, indem Sie im Menü Datei/õffnen oder durch Abwurf auf die Dateiüber das Guitar Pro Hauptfenster.

 

2. Um Guitar Pro zu starten

Gehen Sie in das Menü Anwendungen- Audio-und Video- Guitar Pro 6.

 

 

3.Um Guitar Pro zu deinstallieren

  • Verwenden Sie das Menü System-Administration- Synaptic-Paketverwaltung. Dadurch wird der Paket-Manager gestartet.

  • Klicken Sie auf Status, dann auf installiert. Finden Sie "guitarpro6" in der Liste.

  • Rechter Mausklick auf dem grünen Bereich, und klicken Sie auf "Wählen" für eine vollständige Entfernung.

  • Klicken Sie auf "Anwenden".

 

D. Installation mit Mac OS

1. Um Guitar Pro zu installieren

  • Legen Sie die Guitar Pro DVD-ROM im Ihr Laufwerk

  • Doppelklicken Sie auf das Guitar Pro 6 Symbol auf Ihrem Desktop, dann verschieben Sie das Symbol auf das Symbol „Anwendungen“

  • Um Soundbanken zu installieren, õffnen Sie einfach die GPBANK-Datei, die Sie auf der DVD finden, mit Guitar Pro, indem Sie im Menü Datei/õffnen oder durch Abwurf auf die Dateiüber das Guitar Pro Hauptfenster

 

2. Um Guitar Pro zu starten

Um Guitar Pro zu starten, gehen Sie zu der “Anwendung” Datei, dann doppelklicken Sie auf das Guitar Pro Symbol.

 

 

3. Um Guitar Pro zu deinstallieren

Wenn Sie Guitar Pro deinstallieren wollen, müssen Sie  einfach das GuitarPro Symbol auf den Papierkorb ziehen
