MIDI Import

   Definition : MIDI – Musical Instrument Digital Interface. This is a protocol, a universal language used to transmit digital musical information between computers, synthesizers, sequencers, etc. MIDI files include messages that can precisely describe a score: notes, rhythm, tempo, instrument, etc.

MIDI files include messages that can accurately describe a score: notes, rhythms, tempo, instruments, etc. The audio quality of a MIDI file thus depends on what soundcard your computer is equipped with.

Go down File > Import > MIDI to import MIDI files into Guitar Pro. Guitar Pro supports MIDI 0 and 1 formats.
