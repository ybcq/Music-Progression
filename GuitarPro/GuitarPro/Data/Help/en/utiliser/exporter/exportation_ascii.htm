ASCII Export

   Definition:  The ASCII format is a textual representation of tablature, in which the lines are represented by dashes. This format, though not very attractive, is the only one that allows you to share tablature without specific software. It is commonly used on the Internet. In general, the file extension is .txt or .tab.

The File > Export > ASCII Tab menu lets you export the active track into ASCII format.
