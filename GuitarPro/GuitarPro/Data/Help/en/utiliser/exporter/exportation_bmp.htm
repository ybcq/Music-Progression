PNG Export

The File > Export > PNG allows you to save the score in the form of a picture file. This function is handy if you plan to publish your creations on a web page, for example.

 

The image you get from the export is exactly the same as the image you see in the Guitar Pro editor.

The Export button saves the image.

   Tip: The size of the image is affected by the zoom value. You can therefore obtain images of various sizes depending of what you want to use them for.

   Tip: The PNG format is adapted to computer screens. If you wish to insert your score into a document for print, we recommend you use PDF Export.

   Warning: PNG Export is really only useful in Page mode.
